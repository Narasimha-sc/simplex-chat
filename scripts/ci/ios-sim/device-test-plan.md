# Device test plan: chat profiles, profiles of new connections, self-destruct passcode, deleting the database and the last profile

## Anything unusual

You are looking for regressions, not only running checks. Besides each case's checks, watch for anything a user would consider wrong, on every screen you pass through:

- a crash, the app closing or restarting, a frozen screen;
- an error alert or dialog of any kind ("View crashed", "Error", "Unexpected error", "Connection error", an error code or exception text);
- an action that takes over 30 s, or a spinner that never ends;
- text cut off, overlapping, garbled, untranslated or showing a raw key (such as `chat_item_…`), wrong plurals, empty labels;
- a control that does nothing, a duplicated or missing item, an item in the wrong place or order;
- a state that differs after a restart or after switching profile;
- anything that differs from how the row or the step describes it.

Record each in `report.md` under a heading `## Unusual`, with the case it happened in and the screenshot names, even when every check passes. A case passes only when its checks pass and nothing unusual happened in it; otherwise mark it FAIL and say why. Never stop at a failure: go on with the next case.


The app as the scripted smoke test leaves it: the profile "citester", without conversations. The cases run in the order of the tables and build on each other: do not reorder them. The destructive cases (self-destruct, deleting the database, deleting the last profile) come last.

## Setup

- Contacts connect through the app's preset servers on the internet: use `ui wait "<text>" 120` for a connection.
- **Settings:** open the picker (your profile image, `Image "Account"`), "Settings". Rows used here: "Your privacy" → "SimpleX Lock", and "Chat data" → "Database passphrase & export". Go back with the navigation back buttons; close Settings by swiping it down.
- **The picker** shows the active profile first in its top row, then the other visible profiles, most recently used first; tap another profile's name to switch to it (`ui find <name>`, then `ui tap-xy`).
- **Passcode screens** ("New Passcode", "Confirm Passcode", "Set passcode", "Enter Passcode"; a line under the title names the reason): tap the digits of the pad (`ui tap 1`, …), then "Save", "Confirm" or "Submit" (disabled until at least 4 digits are entered) or "Cancel". The key right of 0 deletes the last digit.
- **Passphrase fields** ("New passphrase…", "Confirm new passphrase…", "Enter passphrase…"): `ui tap-value "<placeholder>"`, then `ui type`; check the value in the tree.
- **Restart:** `ui relaunch`. It waits for "Compose"; when a passcode, passphrase or onboarding screen shows first it may report an error, which is expected where the plan says so: take a shot and continue from the screen.
- **Adding a profile:** picker → "Your chat profiles" → "Add profile" → `ui tap-value "Enter your name…"`, type the name, check the value (fix capitalization), tap "Create profile". Close "Your chat profiles" by swiping it down. When it opens with more than one profile, the alert "Make profile private!" may show: tap "Ok".
- **"Your chat profiles"**: tapping a row makes the profile active. Swiping a row to the right (`ui swipe` from its left part to the right) shows "Hide" / "Unhide" and "Mute"; swiping it to the left shows "Delete". The search field at the top reveals a hidden profile when its password is typed into it.
- **New 1-time link:** "Compose" → "Create 1-time link". The link shows under "Share this 1-time invite link"; the share button right of it (a square with an arrow; take it from `ui tree`) opens the share sheet with "Copy". Below the QR code, "Share profile" shows the profile the link belongs to: tapping that row opens "Select chat profile", which lists your profiles and "Incognito"; tapping one moves the link to it (choosing another profile also makes that profile the active one); go back to the link with the navigation back button. A pending link shows in the chat list as "invited to connect", with "you shared one-time link" (or "you shared one-time link incognito").
- **Connecting by a copied link:** "Compose" → "Scan / Paste link" → "Tap to paste link" ("Allow Paste" if iOS asks) → the alert names the profile that made the link: tap "Open new chat" → tap the "Connect" bar at the bottom of the chat.

In R23.11 the self-destruct passcode is `2468`, changed to `8642`; after it the app passcode is `8642`. Database passphrase in R23.11: `cipass1`. Hidden profile passwords: cibob `cihide1`, cicarol `cihide2`.
