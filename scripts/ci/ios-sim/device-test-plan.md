# Device test plan: onboarding and the first profile (checklist batch B01)

## Anything unusual

You are looking for regressions, not only running checks. Besides each case's checks, watch for anything a user would consider wrong, on every screen you pass through:

- a crash, the app closing or restarting, a frozen screen;
- an error alert or dialog of any kind ("View crashed", "Error", "Unexpected error", "Connection error", an error code or exception text);
- an action that takes over 30 s, or a spinner that never ends;
- text cut off, overlapping, garbled, untranslated or showing a raw key (such as `chat_item_…`), wrong plurals, empty labels;
- a control that does nothing, a duplicated or missing item, an item in the wrong place or order;
- a state that differs after a restart or after switching profile;
- anything that differs from how the row or the step describes it.

Record each in `report.md` under a heading `## Unusual`, with the case it happened in and the screenshot names, even when every check passes. A case passes only when its checks pass and nothing unusual happened in it; otherwise mark it FAIL and say why. Never stop at a failure: go on with the next case.


The app as the scripted smoke test leaves it: the profile "citester" (the keyboard may have changed the typed name: use the name the user picker shows), without conversations, in the one-hand UI. The cases run in the order of the table and build on each other. Case IDs are `R<row>` of the manual checklist; `S<n>` is a setup step.

## Setup and conventions

- **Shot names** take only letters, digits, `-` and `_`: write a case ID with `-` for the dot (`ui shot R1-10-reachable`).
- **Camera:** if iOS asks for camera access when "Scan / Paste link" or "Connect via link or QR code" opens, tap "Don’t Allow" (`ui point` / `ui tap-xy` if the alert is not in the tree); pasting does not need the camera.
- Never open, connect to or message "Ask SimpleX Team" or any other preset contact, group or channel: they reach real people. Only the profiles these cases create are used.
- **User picker:** your profile image in the toolbar (`Image "Account"`, tap its centre with `ui tap-xy`). It shows "Create SimpleX address" (or "Your SimpleX address" once there is one), "Chat preferences", "Your chat profiles", "Settings", and the profiles by name in a row at the top; tapping the active profile's name opens your profile, tapping another name switches to it.
- **Settings:** picker → "Settings". "Appearance", "Notifications", "Network & servers" and "Help & support" (which holds "About SimpleX Chat") are rows of it; the app version row ("v…") at the bottom → "Developer" holds "Chat console" and "Reset all hints". Go back with the navigation back buttons; close Settings by swiping it down.
- **Adding a profile:** picker → "Your chat profiles" → "Add profile". The view "Create your profile" has the field "Enter your name…" (`ui tap-value "Enter your name…"`), "Bio" and the button "Create profile". Type the name and check the field's value in the tree (the keyboard may capitalize it). If "Your chat profiles" shows the alert "Make profile private!", tap "Ok". The new profile becomes the active one; close "Your chat profiles" by swiping it down.
- **Creating a group:** "Compose" → "Create group" → `ui tap-value "Enter group name…"`, type the name, check the value, tap the "Create group" button (the list row, not the title), then "Skip" if it shows.
- **Pasting into a field:** `ui clipboard "<text>"` (or single quotes when the text holds double quotes), tap the field once to focus it and once more for its menu, then tap "Paste" (use `ui tap-xy` on the menu's "Paste").
- **Alerts and sheets:** an alert's buttons are in the tree; if not, use `ui point` at the button's place in the screenshot. Close a sheet by swiping it down.
