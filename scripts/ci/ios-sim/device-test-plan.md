# Device test plan: groups I part 2 (member info, direct chats with members, profile updates, inactive groups, auto-accept, invitations via a group)

## Anything unusual

You are looking for regressions, not only running checks. Besides each case's checks, watch for anything a user would consider wrong, on every screen you pass through:

- a crash, the app closing or restarting, a frozen screen;
- an error alert or dialog of any kind ("View crashed", "Error", "Unexpected error", "Connection error", an error code or exception text);
- an action that takes over 30 s, or a spinner that never ends;
- text cut off, overlapping, garbled, untranslated or showing a raw key (such as `chat_item_…`), wrong plurals, empty labels;
- a control that does nothing, a duplicated or missing item, an item in the wrong place or order;
- a state that differs after a restart or after switching profile;
- anything that differs from how the row or the step describes it.

Record each in `report.md` under a heading `## Unusual`, with the case it happened in and the screenshot names, even when every check passes. A case passes only when its checks pass and nothing unusual happened in it; otherwise mark it FAIL and say why. Never stop at a failure: go on with the next case.


The app as the scripted smoke test leaves it: the profile "citester", without conversations. The cases run in the order of the tables and build on each other: two more profiles in this app, "cibob" and "cicarol", connected to citester by one-time links, and a group "ci club" owned by citester. Do not reorder them.

## Setup

- All profiles live in this one app and connect through the app's preset servers on the internet: deliveries take a few seconds; use `ui wait "<text>" 60` for something another profile sent.
- **Sending a message:** in the chat, tap the message field at the bottom (find it in `ui tree`: the text view next to the send button; placeholder "Message"), `ui type "<text>"`, then tap the send button at the right end of the field. Check the message then shows in the chat.
- **Group info:** tap the group's name at the top of the chat (`ui find "<group name>"`, the element with the smallest y; tap it with `ui tap-xy`). Go back with the navigation back buttons; close a sheet by swiping it down.
- **Member info:** in group info, tap the member's name in the list under the header "N members"; or, in the group chat, tap the member's profile picture left of their message (position from a screenshot, `ui tap-xy`). Member info has three buttons near the top: "message", "call" and "video".
- **Switching profile:** open the picker with your profile image (`Image "Account"`), then tap the other profile's name in the row at the top of the picker (`ui find <name>`, then `ui tap-xy`; the picker's elements are in the tree even while it is closed, so open it first). The picker also has "Settings".
- **Adding a profile:** picker → "Your chat profiles" → "Add profile" → `ui tap-value "Enter your name…"`, type the name, check the field's value in the tree (the keyboard may capitalize it: then fix it), tap "Create profile"; close "Your chat profiles" by swiping it down.
- **Connecting profile A with profile B:** as A: "Compose" → "Create 1-time link"; under "Share this 1-time invite link" the link is a text element whose label is the whole link (`ui find "https://"`): put exactly that label on the clipboard with `ui clipboard "<link>"`; go back to the chat list. Switch to B: "Compose" → "Scan / Paste link" → "Tap to paste link" (if iOS asks to allow pasting, tap "Allow Paste"). An alert names A with "Open new chat": tap it (if it asks "Use current profile" instead, tap that). The chat with A opens with a "Connect" bar at the bottom: tap it. Switch to A and wait up to 60 s until its chat list shows B.
- **Creating a group and inviting contacts:** "Compose" → "Create group" → `ui tap-value "Enter group name…"`, type the name (check the value) → "Create group"; on the members screen tap each contact in the list, then "Invite to group"; or "Skip" (top right).
- **Group invitations:** the invited profile gets, in its chat with the inviting contact, a card with the group's name, "You are invited to group" and "Tap to join"; tapping "Tap to join" joins, and the card then says "You joined this group".
- **Group preferences:** group info → "Group preferences"; each feature is a switch named after it; then "Save and notify group members".
- **Developer tools:** picker → "Settings", scroll to the bottom, the app version row ("v…") → "Developer". It has "Chat console" and the switch "Show developer options". With that switch on, group info and member info end with a section "For console" with "Local name" and "Database ID".
- **The photo picker** ("Choose from library") is iOS's: tap the test card's thumbnail (the colour bars), then "Add" if the picker shows it.
