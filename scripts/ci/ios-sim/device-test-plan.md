# Device test plan: SimpleX Lock, the chat database and its passphrase, message deletion and hidden profiles

## Anything unusual

You are looking for regressions, not only running checks. Besides each case's checks, watch for anything a user would consider wrong, on every screen you pass through:

- a crash, the app closing or restarting, a frozen screen;
- an error alert or dialog of any kind ("View crashed", "Error", "Unexpected error", "Connection error", an error code or exception text);
- an action that takes over 30 s, or a spinner that never ends;
- text cut off, overlapping, garbled, untranslated or showing a raw key (such as `chat_item_…`), wrong plurals, empty labels;
- a control that does nothing, a duplicated or missing item, an item in the wrong place or order;
- a state that differs after a restart or after switching profile;
- anything that differs from how the row or the step describes it.

Record each in `report.md` under a heading `## Unusual`, with the case it happened in and the screenshot names, even when every check passes. A case passes only when its checks pass and nothing unusual happened in it; otherwise mark it FAIL and say why. Never stop at a failure: go on with the next case.


The app as the scripted smoke test leaves it: the profile "citester", without conversations. The cases run in the order of the tables and build on each other: do not reorder them. Destructive cases (passphrase changes, database import) come last.

## Setup

- The simulator has no Face ID, Touch ID or device passcode enrolled: iOS's own ("System") authentication is unavailable here, by design of this test. Moving the app to the background is not possible with `ui`.
- Contacts connect through the app's preset servers on the internet: use `ui wait "<text>" 120` for a connection.
- **Settings:** open the picker (your profile image, `Image "Account"`), "Settings". Rows used here: "Your privacy" → "SimpleX Lock" (its value shows "Off", "System" or "Passcode"), and "Chat data" → "Database passphrase & export". Go back with the navigation back buttons; close Settings by swiping it down.
- **Passcode screens** ("New Passcode", "Confirm Passcode", "Enter Passcode", "Current Passcode"; a line under the title names the reason): tap the digits of the pad (`ui tap 1`, …), then "Save", "Confirm" or "Submit" (disabled until at least 4 digits are entered) or "Cancel". The entered digits show as dots.
- **Passphrase fields** ("Current passphrase…", "New passphrase…", "Confirm new passphrase…", "Enter passphrase…"): `ui tap-value "<placeholder>"`, then `ui type`; check the value in the tree. The eye image at the left end of each field (no label; tap it with `ui tap-xy`) shows or hides the text.
- **Restart:** `ui relaunch`. It waits for "Compose"; when a passphrase screen shows first it reports an error, which is expected where the plan says so: take a shot and continue from the screen.
- **Adding a profile:** picker → "Your chat profiles" → "Add profile" → `ui tap-value "Enter your name…"`, type the name, check the value (fix capitalization), tap "Create profile". Close "Your chat profiles" by swiping it down. When "Your chat profiles" opens with more than one profile, the alert "Make profile private!" may show: tap "Ok".
- **Switching profile:** open the picker, tap the other profile's name in the row at the top of the picker (`ui find <name>`, then `ui tap-xy`).
- **Creating a group:** "Compose" → "Create group" → `ui tap-value "Enter group name…"`, type the name, check the value → tap the "Create group" button (the list row, not the title) → "Skip" if it shows; go back to the chat list.
- **Connecting two profiles:** as the inviting profile: "Compose" → "Create 1-time link"; wait for the link under "Share this 1-time invite link"; tap the share button right of the link (its icon is a square with an arrow; take it from `ui tree`), then "Copy" in the share sheet; close the sheet and go back to the chat list. Switch to the other profile: "Compose" → "Scan / Paste link" → "Tap to paste link" ("Allow Paste" if iOS asks) → the alert names the inviting profile: tap "Open new chat" → tap the "Connect" bar at the bottom of the chat.
- **Chat info:** tap the chat's name at the top of the chat.
- **Passcodes and passphrases used:** app passcode `1234`, changed to `5678` in R23.8; wrong passcode `9999`. Database passphrase `cipass1` from R57.10, `cipass2` from R57.11; wrong passphrase `wrongpass`. Hidden profile password `cihide1`.
