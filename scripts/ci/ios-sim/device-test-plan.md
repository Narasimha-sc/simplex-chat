# Device test plan: operators, servers and chat relays (part 2)

## Anything unusual

You are looking for regressions, not only running checks. Besides each case's checks, watch for anything a user would consider wrong, on every screen you pass through:

- a crash, the app closing or restarting, a frozen screen;
- an error alert or dialog of any kind ("View crashed", "Error", "Unexpected error", "Connection error", an error code or exception text);
- an action that takes over 30 s, or a spinner that never ends;
- text cut off, overlapping, garbled, untranslated or showing a raw key (such as `chat_item_…`), wrong plurals, empty labels;
- a control that does nothing, a duplicated or missing item, an item in the wrong place or order;
- a state that differs after a restart or after switching profile;
- anything that differs from how the row or the step describes it.

Record each in `report.md` under a heading `## Unusual`, with the case it happened in and the screenshot names, even when every check passes. A case passes only when its checks pass and nothing unusual happened in it; otherwise mark it FAIL and say why. Never stop at a failure: go on with the next case.


The app as the scripted smoke test leaves it: the profile "citester", without conversations, onboarded with both preset operators selected. The cases run in the order of the tables and build on each other: S2 turns Flux off, S3 adds the profile "cibob", and later cases add and remove servers and relays. Use only this app's own profiles and the preset servers; no test backend runs.

- **Network & servers:** open the picker (your profile image, `Image "Account"`), "Settings", "Network & servers". It lists "Preset servers" ("SimpleX Chat", "Flux"), "Messages & files" ("Your servers"), "Save servers" (disabled when it can't be used; errors show below it) and "Network connection". Go back with the navigation back buttons (Network & servers' own is "Back"); close Settings by swiping it down (`ui swipe 200 120 200 800`). Leaving Network & servers with "Back" and unsaved valid changes shows "Save servers?" with "Save" and "Exit without saving".
- **Operator page:** tap "SimpleX Chat" or "Flux". Titled "SimpleX Chat servers"; sections "Operator" (logo row, toggle "Use servers", errors or warnings below), "Chat relays" (preset relays "SimpleX Chat Relay 1", "…2", "…3"), "Use for messages" (toggles "To receive", "For private routing", "To resolve names"), "Message servers", "Added message servers", "Use for files" (toggle "To send"), "Media & file servers", "Test servers".
- **A server's page:** tap its host name. A preset server shows "Preset server address"; an added one shows "Your server address" (a text view), "Use server" ("Test server", toggle "Use for new connections") and, while it is in use, "Use for messages" with the pickers "To receive", "For private routing" and "To resolve names" (values "default (yes)" / "default (no)", "yes", "no"). There is no delete button on the page: an added server or relay is deleted by swiping its row left in the list (`ui swipe <x> <y> <x-250> <y>`) and tapping the red delete button that appears, or with the edit button at the right of the navigation bar. A server in error shows a red exclamation mark left of its host name, and Network & servers then shows "Errors in servers configuration." (or a specific error) below a disabled "Save servers".
- **Add a server:** Network & servers → "Your servers" → "Add server" → "Enter server manually". On "New server", `ui clipboard "<address>"`, tap the empty text view under "Your server address" once to focus it and once more for its menu, tap "Paste" (`ui find Paste`, `ui tap-xy`), check the value in the tree; turn "Use for new connections" on when a step says so; tap "Back" to add it. A server on an operator's domain shows the alert "Operator server" with "Server added to operator SimpleX Chat." (tap "Ok") and goes to that operator's "Added message servers"; any other goes to "Your servers".
- **Add a chat relay:** "Your servers" → "Add server" → "Chat relay". "New chat relay" has a text view under "Your relay address" (paste into it as above) and the field "Enter relay name…" (`ui tap-value "Enter relay name…"`, then `ui type`), then "Use relay" ("Test relay", toggle "Use for new channels"). "Back" adds it to "Your servers" → "Chat relays", or shows an alert when the name or address is invalid. A preset relay's page ("Chat relay") shows "Preset relay address" and "Preset relay name"; an added relay's page has "Delete relay".
- **Adding a profile:** picker → "Your chat profiles" → "Add profile" → `ui tap-value "Enter your name…"`, type the name, check the value in the tree, tap "Create profile". Close "Your chat profiles" by swiping it down.
- **Switching profile:** open the picker with your profile image, then tap the other profile's name in the row at the top of the picker (`ui find <name>`, `ui tap-xy`).
